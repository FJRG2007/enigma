# Codebase memory / code graph (NATIVE) (`src/codegraph.ts` + `enigma codegraph`)

- WHAT: a fully NATIVE, zero-dependency TS code-intelligence engine. Indexes a project's source into a knowledge graph - files, the symbols each defines (function/class/interface/type/struct/enum/trait/module), the modules it imports, and cross-file symbol references - and answers architecture/search/schema queries. STRUCTURAL code memory, complementary to `recall` (session memory). NO external binary, NO npx, NO third-party package (a prior draft wrapped the external `codebase-memory-mcp`; the user required native, so it was reimplemented - that C engine is un-portable to enigma's zero-dep TS, so this is honest "structural-lite", NOT a 1:1 port). De-branding rule still holds: no upstream project name anywhere. Study clone kept for reference only: `references/repos/codebase-memory-mcp` (gitignored, MIT).
- ENGINE (`src/codegraph.ts`, Node-builtins only): `walk()` scans the tree (IGNORE_DIRS incl. node_modules/dist/target/etc.; NOTE `bin`/`obj` were deliberately NOT ignored - they collide with legit source dirs like `src/bin`), capped MAX_FILES=8000 / MAX_FILE_BYTES=512KB. `symRules(lang)` + `importSpecs(lang, content)` are the per-language regex extractors (ts/js/python/go/rust/java/csharp/kotlin/ruby/php/c/cpp); `lineResolver` binary-searches newline offsets for symbol lines. Build: resolve relative imports to intra-project files (`resolveRelative`, RESOLVE_EXTS + index files) -> `importEdges`; unresolved specifiers -> `externalModules` counts. Cross-file REFERENCES: tokenize each file's identifiers, count any that name a symbol defined in ANOTHER file (best-effort call graph without full resolution; names <3 chars skipped as collision-prone). Persisted per project as JSON under `~/.enigma/codegraph` (`ENIGMA_CODEGRAPH_DIR` overrides): `projects.json` index + `<sha1(root)[:12]>.json` graph. Public API: `indexProject(root?)`, `listProjects`, `codeGraphProjects` (alias), `codeGraphArchitecture(project?)` (languages/entryPoints/hotspots/packages/externalModules; entryPoints = files with no inbound import OR matching main|index|cli|app|server|bin), `codeGraphSchema` (node/edge label counts), `searchGraph(project?, {name,kind,limit})`, `codeGraphStatus`, `codeGraphAvailable` (always true - native), `resetCodeGraph`. Verified on enigma's own src: 173 files / 2421 symbols / 606 import edges.
- CONFIG: `codeGraph` toggle (config.ts, default OFF/opt-in). Wired as a custom `setCodeGraph` in settings-registry.ts -> `setEnigmaToggle` + `applyMcpToggle` (the tools ride the EXISTING `enigma` MCP server, NOT a second server).
- MCP (native, via `enigma mcp`): `mcp.ts` `mcpEnabled()` now = `compress || recall || codeGraph`, so enabling codeGraph registers the enigma server. `CODEGRAPH_TOOLS` (`enigma_codegraph_index`/`_projects`/`_search`/`_architecture`) are appended to `toolList()` only when `config.codeGraph`; `callTool` cases gate on the flag and call the engine directly. This is the recall/compress pattern - do NOT deploy a separate managed server.
- DASHBOARD: bridge `dashboard-codegraph.ts` (`codeGraphDashboard({project})` + `applyCodeGraphAction` toggle|index|refresh - calls the engine in-process); origin-guarded `GET/POST /api/codegraph` in dashboard.ts (POST body carries `on`/`project`/`root`); a "Code graph" tab in `packages/dashboard/assets/index.html` with a REAL switch (`class="toggle" data-kind="bool"` - the sliding-knob switch, NOT a text on/off button; this was a repeat complaint - ALWAYS use `data-kind="bool"` for bool controls), an "Index a project" input, a projects list and a defensive `cgSection`/`cgVal` architecture/schema renderer. `codeGraph` added to the "Enigma Systems" panel + `dashboard-status.ts`. demo-mock stubs `/api/codegraph` (native shape) + `codeGraph:true` in STATUS; `scripts/screenshot.mjs` too. The old "Could not reach the server" was the external-wrapper era (route/backend mismatch); native = enigma's own backend, no external dep.
- CLI: `enigma codegraph <status|on|off|index [path]|projects|arch [project]|search <name>>` (`runCodeGraphCli`, native). In COMMANDS + printHelp, dispatched next to `recall`.
- TESTS: `tests/codegraph.test.ts` (bun; temp HOME + `ENIGMA_CODEGRAPH_DIR` + `ENIGMA_CONFIG_HOME` set BEFORE import; indexes a synthetic multi-lang temp project, asserts symbol/import extraction, node_modules skipped, search by name/kind, architecture languages/entryPoints/hotspots/externalModules, schema counts, re-index dedupe + reset). Wired into ci.yml.
