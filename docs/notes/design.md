# Design extraction (`enigma design`, `src/design/`)

- WHAT: reverse-engineers a design system from a live URL, a local project or a git repository into `<out>/<name>-design/`: `DESIGN.md`, `SKILL.md` (agent skill, every reference inlined), `references/*.md`, `tokens/*.json`, `fonts/`, screenshots, and a `<name>-design.skill` ZIP; then copies the skill folder into each detected agent's skills dir (`-g` default, `-l` project, `-a` to pick, `--no-install`). Static analysis, no model, no API key.
- ORIGIN: a native port of the heuristics of amaancoderx/npxskillui (MIT, Copyright (c) Amaan; study clone `references/repos/npxskillui`, ported from `bc913a8`). De-branded: no upstream name in user-facing text. ZERO runtime deps - every package upstream needed was replaced: css-tree -> `css-parse.ts` (a tolerant declaration/at-rule walker that never throws), jiti/`Function` -> `object-literal.ts`, archiver -> `write/zip.ts`, Playwright -> `browser/` (raw CDP), simple-git/tmp -> `git clone` spawned with an arg array, chalk/ora/boxen/prompts -> plain lines + @clack/prompts.
- REPOSITORY CODE IS NEVER EXECUTED. Upstream `require`d `tailwind.config.js`/`theme.ts` through jiti and fell back to `Function(...)` - running arbitrary code from a repo the user does not own. `object-literal.ts` reads the exported object statically: literals come back, a bare identifier resolves to a top-level literal const, everything that would need evaluation (calls, spreads, member access, `${}` templates) is DROPPED, never guessed. `tests/design/parsing.test.ts` pins that a config with a `fs.writeFileSync` side effect leaves no file behind.
- BROWSER = THE ONE ALREADY INSTALLED, HEADLESS, THROWAWAY PROFILE. `browser/chrome.ts` finds Chrome/Chromium/Edge/Brave (chrome-launcher's paths; `--browser`, `ENIGMA_BROWSER`, `CHROME_PATH` first), launches `--headless=new --remote-debugging-port=0 --user-data-dir=<mkdtemp>`, reads the ws endpoint from stderr (DevToolsActivePort file as fallback). `cdp.ts` is a minimal client over the runtime's WebSocket with flattened sessions; one browser per run, a tab per step. Cleanup is three-layered: `Browser.close` -> kill -> await `exit` -> rm profile; a `process.on("exit")` hook kills any still-live child; the CLI maps SIGINT to `exit(130)` so Ctrl+C goes through that hook. The ultra test asserts no `enigma-design-*` temp dir survives. No browser -> HTTP-only URL mode with a warning; `--no-browser` forces that (and `--ultra --no-browser` is a usage error).
- NO THIRD-PARTY SERVICES. Upstream screenshotted through microlink.io (sending every URL to a third party) and fetched fonts with a Google API key hard-coded in its source. Here the homepage capture is local, and `fonts.ts` uses the public CSS2 endpoint a browser uses (browser UA so it serves woff2): variable families via `wght@100..900` (one file), static ones weight by weight, Latin subset only. Self-hosted site fonts are usually licensed to that site, so they are copied only with `--bundle-site-fonts`; otherwise their URLs stay in the output.
- EXTRACTED TEXT IS DATA, AND IT ENDS UP IN AN AGENT'S CONTEXT. Everything from the site (labels, class names, titles, CSS values, HTML samples) goes through `write/md.ts`: inline values via `code()` (a fence longer than any backtick run, newlines collapsed), prose via `text()` (markdown-active chars escaped), samples via `fenced()` (fence longer than any inner run). SKILL.md states that quoted values describe the design and are never instructions.
- ROLES: NAMES FIRST, ONE COLOR PER ROLE (`roles.ts`, `normalize.ts`). Upstream assigned roles mostly by lightness/hue and could give two colors the same role; on enigma's own site it called a dark theme light with `#ffffff` as background. Now: exact role names (`bg`, `text`, `foreground`, `muted-foreground`, `border`, `accent`, `primary`, `danger`, ...) win; qualified names (`warning-bg`, `accent2`, `border-soft`) are variants and never take a role; a hex shared by `--bg` and `--info-bg` keeps the outright name (`preferredName`); a name already holding a role does not get a second, hue-based one (its other-scheme value); shadcn's `--muted` is a surface when `--muted-foreground` exists; a named background settles light vs dark. With a browser, the painted canvas and body text colors (`page-background`/`page-text`) beat everything.
- TYPE SCALE FROM THE RENDER. When the browser measured `h1` and running text, `renderedTypography` uses those families/sizes/weights/line heights directly (body = the most common paragraph size, not the first `<p>`, which is often a hero subtitle). Frequency inference is the fallback. The typography rules text is derived from the tokens (measured weights and line heights), never a fixed "600-700".
- CROSS-ORIGIN CSS: page script cannot read a CDN stylesheet's rules, so upstream reported 0 keyframes on most production sites. `Page.styleSheetTexts()` reads every sheet over the DevTools CSS domain (`CSS.enable` replays `styleSheetAdded` for loaded sheets) and `ultra/keyframes.ts` parses keyframes and their usage from text. stripe.com: 0 -> 10 keyframes.
- OTHER FIXES OVER UPSTREAM, each found on a real run: `<style>` blocks of HTML/Vue/Svelte/Astro are stylesheets too (a component project keeps its CSS there); SCSS/LESS top-level `$var`/`@var` are named tokens; `--bg` was not recognized as a color variable; a variable `@font-face` weight range is `variable`, not `1`; `app/` and `app/components/` no longer scan the same file twice; redirects no longer capture the same page twice (`home` + `en-es`); shared stylesheets are fetched once per crawl, six at a time; responses are capped at 10 MB and 15 s; `git clone` refuses `-`-prefixed URLs, sets `GIT_TERMINAL_PROMPT=0` and times out.
- OUTPUT SAFETY: the output folder and each installed skill folder carry `.enigma-design.json`; a re-run replaces only folders with that marker (or empty/absent ones). Anything else needs `--force` - a user's own `<name>-design` folder or a hand-written skill of the same name is never overwritten. Installed copies skip the `.skill` ZIP and the `CLAUDE.md`/`AGENTS.md` that only serve the `cd <folder> && <agent>` workflow. enigma's skill prune ignores these folders (no managed provider).
- TESTS (`tests/design/`): `parsing` (walker, static reader, keyframes, token pass), `profile` (roles, rendered type, md escaping, ZIP read back with inflate + CRC, argument validation), `run` (fixture project end to end with install into a temp `ENIGMA_CONFIG_HOME`, foreign-folder refusal, URL mode against a local HTTP server, and - when a browser exists - full ultra mode against it, asserting screenshots, keyframes, states and no leftover profile). One process per file: `bun test tests/design/run.test.ts`.
