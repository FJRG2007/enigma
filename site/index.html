Everything you need to work with a coding agent

Enigma installs shared engineering policy skills into the agents you actually use, sets up portable git security hooks, and ships a local savings dashboard - all from one command.

$ curl -fsSL https://raw.githubusercontent.com/FJRG2007/enigma/main/scripts/install.sh | sh
Works with Claude Code Codex opencode
What you get

Production engineering, deployed into your agent

Authored once, deployed to every agent you select - and kept current automatically.

Policy skills, everywhere

Engineering policy skills (security, testing, git, style, debugging, anti-overengineering...) installed into Claude Code, Codex and opencode, sealed with content hashes so tampering is detected.

Per-agent scoping

Keep a skill for Claude Code but not opencode. Turn any skill on or off per agent, from the CLI, the TUI or the dashboard.

Git security hooks

A portable, dependency-free commit guard for any repo: blocks secrets, .env files and dependency dirs before they are committed. Commit .githooks/ and the whole team inherits it.

Local savings dashboard

A loopback browser dashboard of measured token savings and real Claude usage - cost, windows, breakdowns - served at http://enigma. Nothing leaves your machine.

Multi-account + profiles

Several logins per tool without logging out, each in its own config dir, switched OS-agnostically. Profiles pin one account per tool and drive every launch.

Context compression

A native, dependency-free engine that shrinks large tool outputs, logs and text before they reach the model - the same information in far fewer tokens, reversibly.

Privacy defaults

Sensible defaults at install: GitHub CLI telemetry off, the agent kept from attributing commits to itself, and an opt-in prompt secret guard.

Built-in /improve

A slash command on every agent: an implement mode that edits a focused area (ui, security, performance...) and a read-only advisor mode that audits and writes plans for another agent to execute.

Measured, not invented

See what you actually save

Token and money savings from compression, plus real Claude usage read from your own session transcripts. Honest by design - enigma reports only what it can measure.
