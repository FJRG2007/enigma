A flag is an image. The emoji version of it is the thing this component exists to replace:
a flag emoji is a pair of regional-indicator code points (`U+1F1EA U+1F1F8` for Spain), and
**Windows has never shipped a glyph for that pair**, so it renders as the two bare letters
"ES" for most desktop readers. There is no font stack that fixes it, and on the platforms
that do draw a flag, each one draws a different one.

## Usage

<Frameworks>
    <div slot="react">
```tsx
import { Flag } from "@enigmax/primitives/react";

<Flag code="es" />                          // 4:3, 16px tall, from the CDN
<Flag code="es" shape="circle" size={20} /> // round, for a chip or an avatar row
<Flag code="en-GB" label="United Kingdom" /> // labelled: it is the only content
```
    </div>
    <div slot="vanilla">
```js
import { flagAttributes } from "@enigmax/primitives";

const img = document.createElement("img");
for (const [name, value] of Object.entries(flagAttributes("es", { shape: "circle" }))) {
    img.setAttribute(name, String(value));
}
```
    </div>
</Frameworks>

## Where the images come from

Two upstream sets, both SVG, both served from jsDelivr by default:

| Shape | Set | Ratio |
| --- | --- | --- |
| `rect` (default) | [lipis/flag-icons](https://github.com/lipis/flag-icons) `4x3` | 4:3 |
| `square` | lipis/flag-icons `1x1` | 1:1 |
| `circle` | [HatScripts/circle-flags](https://github.com/HatScripts/circle-flags) | 1:1 |

Nothing has to be installed to use them. For a project that will not make a third-party
request at runtime - an offline install, a CSP with no `img-src` for a CDN, a build that
must not break the day a CDN does - the same files are downloaded into the project:

<Command command="enigma add flags --flags local" />

It asks which sets, which countries and which formats, and writes
`public/flags/<shape>/<code>.<format>`. Non-interactively it takes every set and every
country. Then one line at startup moves the whole app onto those files:

```ts
import { configureFlags } from "@enigmax/primitives";

configureFlags({ source: "local", basePath: "/flags" });
```

`source` also takes a URL of your own, for a mirror with the same layout.

| Flag | |
| --- | --- |
| `--flags cdn\|local` | CDN, or files in the project |
| `--flag-shapes rect,square,circle\|all` | which sets to download |
| `--flag-formats svg,png,webp` | png and webp are rasterised locally and need `sharp` |
| `--countries es,fr,us\|all` | which countries |
| `--flags-out <dir>` | default `public/flags` |

**SVG is the only format the two upstreams publish**, so a CDN can serve nothing else. Ask
the CDN for `webp` and you get SVG plus one warning in development; `png` and `webp` are for
a local set, where they are rasterised from the SVG at download time.

## The code you pass

`code` takes what a codebase already holds: `es`, `ES`, `en-GB`, `es_ES`, a subdivision both
sets publish (`gb-eng`, `au-nsw`, `es-ct`), or the emoji flag you are replacing - so a
migration is the component and nothing else.

A BCP 47 tag is read by its **casing**, before anything is lowercased: `es-ES` is a locale
and means the flag `es`, while `es-ct` is Catalonia and means the file `es-ct`. Lowercasing
first makes those the same string, and then one of them is always wrong.

A code that resolves to nothing renders `fallback` (nothing, by default). Never a broken
image: a 404 with no alt text beside a country name is worse than no flag.

## Labels

`label` is the accessible name and there is no default for it. Without one the flag is
**decorative**: empty `alt` and `aria-hidden`, which is correct beside a country name that
is already there - the reader hears it once instead of twice. Pass `label` when the flag is
the only content, as in a compact language switcher.

A name is never invented from the code. "ES" read out by a screen reader is not a country,
and a name guessed in the reader's wrong language is worse than silence.

| Prop | |
| --- | --- |
| `code` | `es`, `ES`, `en-GB`, `gb-eng`, or the emoji |
| `label` | Accessible name. Omitted means decorative |
| `shape` | `rect` (default), `square`, `circle` |
| `size` | Rendered height in px, default 16. Width follows the shape |
| `format` | `svg` (default), `png`, `webp` |
| `source` | `cdn` (default), `local`, or a base URL |
| `basePath` | Where a local set is served from, default `/flags` |
| `fallback` | Rendered when the code resolves to nothing |

Styling hooks: `[data-enigma-flag]`, plus `[data-flag-shape]` and `[data-flag-code]`.
