Orion installs on demand and launches into its own agent context with a browser already wired. It reuses one of your existing logins.

## Requirements

Chrome and Node on the machine. The browser runs an isolated profile, never your own logins.

## Install and launch

<Cmd name="enigma agent install orion" ex={["enigma agent install orion", "enigma agent list"]}>
Fetch the agent (the `@enigmax/orion` asset package) into `~/.enigma/packs/orion`. You can skip this - launching also fetches on demand.
</Cmd>

<Cmd name="enigma orion [account]" ex={["enigma orion", "enigma orion work", "enigma orion --tool codex"]}>
Launch a coding agent inside Orion's isolated context with only Orion's skills, commands and browser. With no account it uses the pinned agent account, else your active profile's account, else the tool's active account. Defaults to Claude Code; target another agent with `--tool`.
</Cmd>

Inside the session, start with `/sweep` for a full pass, or `/flow`, `/perf` and `/scale` for one area. See <a href={docHref("orion/commands")}>Commands</a>.

## The browser

Orion's Chrome DevTools MCP server is registered on every launch - there is no `enigma agent setup orion` step. It follows the same `browser` toggle as your other agents: turn it off with `enigma config browser off` and the next launch removes it from Orion's context.

## Which account Orion uses

<Cmd name="enigma agent use orion <account|->" ex={["enigma agent use orion work", "enigma agent use orion -"]}>
Pin which login seeds Orion by default (`-` clears the pin). `enigma orion <account>` overrides it for a single launch.
</Cmd>

You can also manage Orion from the dashboard's **Agents** tab. See <a href={docHref("packs")}>Agents</a> for how isolation and seeding work across every agent.
