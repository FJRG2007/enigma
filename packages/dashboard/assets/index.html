    Pipeline settings
    What the daemon runs and how hard it tries. Model and auto-fix limits are what a run's duration and token cost actually hang on.
    Agent

    Auto-fix attempts
    Follow-up rounds a step gets before it pauses for you. Every round is another full agent pass over the diff, so this is the setting that multiplies a run's cost. 0 pauses immediately.
    Repository configuration
    Committed with the repository and merged over the global config. Only the fields the gate trusts from a branch take effect.

    Packs

    Optional harness packs you can add on demand. Each runs in its own isolated agent context, so its skills and commands never load into your normal coding agent. Launch a pack from a terminal with enigma <pack>.

    SSH

    Save each server once - host, user, key or password, jump host - then reach it from a terminal with enigma ssh <alias>. Passwords are stored encrypted and auto-filled with no extra tools. Tunnels are managed separately below (start/stop, re-point to any server). The browser cannot open a shell, so Connect copies the command for you to paste.
