# /unknowns

Follow REA's `audit_residual_unknowns` workflow for the current session.

1. List the residual unknowns REA holds for the open target, plus any you stated in this
   conversation.
2. For each, say what evidence would resolve it and whether a tool here can produce it.
3. Resolve those that can be resolved now; leave the rest open with the reason.
4. Report what was resolved, with its evidence, and what remains.
